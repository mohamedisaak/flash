# Flash — Learning Curriculum

This folder is a **complete, self-study software engineering curriculum built
from the actual source code of this project.** As the platform is built feature
by feature, matching lessons appear here explaining *why* each file, model,
endpoint, and config exists — starting from beginner level and building up.

If you read this repository top to bottom, you should be able to learn every
technology it uses.

## How to use it

1. Start with [`00-introduction/`](00-introduction/README.md) — it explains the
   lesson format, exercises, and the recommended learning order.
2. Follow a roadmap in [`39-roadmaps/`](39-roadmaps/README.md) (added as the
   project matures), or just read the numbered folders in order.
3. Each lesson pairs with real code. When a lesson references a file (e.g.
   `apps/articles/models.py`), open that file alongside the lesson.
